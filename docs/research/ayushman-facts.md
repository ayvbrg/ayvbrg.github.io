## Short factual bio sketch

Ayushman Buragohain is a Bengaluru-based research engineer whose current
[GitHub profile](https://github.com/ayvbrg) identifies him as “Research Engineer
@dashtoon.” His public work centers on computer vision and generative media:
he is the principal GitHub contributor to Dashverse's open-source
[HunyuanVideo Keyframe Control LoRA](https://github.com/Dashverse/hunyuan-video-keyframe-control-lora/graphs/contributors),
has authored several technical posts on the
[Dashverse Insiders author page](https://insiders.dashtoon.com/author/ayushman/),
and maintains earlier open-source projects in object detection and model
training. He also co-authored the peer-reviewed paper
[“A deep transfer learning based approach to detect COVID-19 waste”](https://doi.org/10.1002/itl2.327)
and was part of the fifth-place “Ayushman Nischay Shivam” team in the
SIIM-FISABIO-RSNA COVID-19 Detection Kaggle competition, documented in the
team's [solution repository](https://github.com/ayvbrg/SIIM-COVID19-DETECTION-KAGGLE).

The current GitHub handle is `ayvbrg`. `benihime91` is strongly evidenced as a
former GitHub handle and remains his Kaggle handle: the current account owns a
historical [profile repository named `benihime91`](https://github.com/ayvbrg/benihime91),
that repository's README links `benihime91` accounts on GitHub-adjacent
services and Kaggle, and old repository URLs such as
[`benihime91/SIIM-COVID19-DETECTION-KAGGLE`](https://github.com/benihime91/SIIM-COVID19-DETECTION-KAGGLE)
redirect to the current `ayvbrg` repository. Because GitHub's old bare user URL
now returns 404 and GitHub exposes no public account-history page, “former
username” remains an extremely strong inference rather than a platform-issued
rename record.

## Notable work and public evidence

  his `ayvbrg` account is the repository's principal listed
  [contributor](https://github.com/Dashverse/hunyuan-video-keyframe-control-lora/graphs/contributors),
  and the repository publishes training code, inference code, and links to

- The company author page credits him with five technical articles:
  [DashAnime XL 1.0](https://insiders.dashtoon.com/dashanimexl/) (2024),
  [adversarial diffusion distillation](https://insiders.dashtoon.com/exploring-the-future-of-comic-generation-insights-from-our-adversarial-diffusion-distillation-poc/)

  [Flux-driven ControlNet integration](https://insiders.dashtoon.com/improving-control-in-flux-driven-image-generation-with-custom-controlnet-integration/)

  [multi-identity image editing with UMO and Qwen Edit](https://insiders.dashtoon.com/no-more-face-mashups-umo-meets-qwen-edit/)
